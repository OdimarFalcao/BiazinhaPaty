# Bia's Sunset Party

Convite interativo em pixel art, com formulário de confirmação e exportação local do voto em CSV.

## Publicar na Vercel

1. Importe este repositório na Vercel.
2. Mantenha o diretório raiz do projeto como `.`.
3. Clique em **Deploy** — não é necessário configurar comando de build.

O formulário envia os votos por `/api/votes`. A função serverless valida os dados e os encaminha para a lista de votos existente do site da Bia.
